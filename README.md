An entry for the make.fun bounty "The Worst App Idea Ever Pitched": a program that writes one original one-line pitch for the worst, most useless app imaginable to `/output/entry.txt`.

## The entry

> Tupperware Tindr matches your leftover containers with their missing lids across the city, so orphaned tubs can finally find love, and your kitchen drawers can finally stop holding a grudge against you.

The entry line is 202 characters long, a single sentence.

## Run

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt`. Deterministic: no network, no randomness.
